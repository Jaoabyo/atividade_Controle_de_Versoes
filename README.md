# Atividade — Controle de Versões

Projeto desenvolvido como parte da atividade acadêmica da disciplina de **Controle de Versões**, com o objetivo de praticar o uso do **Git** e do **GitHub** no gerenciamento e versionamento de um projeto.

## Sobre o projeto

Este projeto consiste em uma página web simples desenvolvida com **HTML e CSS**, utilizada para colocar em prática os principais conceitos de controle de versões.

Durante o desenvolvimento foram realizados procedimentos como:

* Criação de um repositório no GitHub;
* Clonagem do repositório para o ambiente local;
* Criação e organização dos arquivos do projeto;
* Adição de arquivos utilizando `git add`;
* Criação de commits utilizando `git commit`;
* Envio das alterações para o GitHub utilizando `git push`;
* Utilização do branch principal `main`;
* Publicação do projeto utilizando o **GitHub Pages**.

## Controle de versões

O projeto foi desenvolvido utilizando Git para acompanhar as alterações realizadas durante a atividade.

Os principais comandos utilizados foram:

```bash
git clone <URL_DO_REPOSITORIO>
git status
git add .
git commit -m "Mensagem do commit"
git push origin main
```

O histórico de commits pode ser consultado diretamente no repositório do GitHub.

## Como executar o projeto localmente

### 1. Clonar o repositório

```bash
git clone https://github.com/Jaoabyo/atividade_Controle_de_Versoes.git
```

### 2. Acessar a pasta

```bash
cd atividade_Controle_de_Versoes
```

### 3. Abrir o projeto

Abra o arquivo `index.html` em um navegador.

Também é possível abrir a pasta no **Visual Studio Code** e utilizar uma extensão como o Live Server para visualizar a página durante o desenvolvimento.

A atividade tem como finalidade demonstrar, na prática, a utilização de ferramentas de controle de versão para organizar, registrar e disponibilizar um projeto de software.

**Desenvolvimento → Alteração → `git add` → `git commit` → `git push` → GitHub**
